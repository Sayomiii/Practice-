# Title
 WEATHER API PROJECT
## Description
This project extract an API URL from an open Weather website called London Weather API with a valid API key called "WEATHER_API_KEY" and save on json file called london_weather.json. 
## Tools Used

-Python
-Requests
-JSON
-python-dotenv (for securely storing the API key)
-gitignore
-os (for loading the dotenv)

## Data Extracted as Result
-Location
-Temperature
-Weather condition

## Output 
The result is saved in the london_weather.json

## Objectives
-Understand web scraping and API requests.
-Extract and process data using Python.
-Save extracted data in JSON format.
-Practise handling errors and protecting API keys.

## Run the Python script using:
`` bash
python weather_api.py
``
