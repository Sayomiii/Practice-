# Title
 Web Scraping
 Website: https://books.toscrape.com/

## Description
This project uses Python to scrape book information from a website and save it in a JSON file.

## Tools Used
- Python
- Requests
- BeautifulSoup
- JSON

## Data Extracted
- Book title
- Price
- Rating
- Availability

## Output
The extracted information is saved in books.json.

## Objective
To scrape the data succesfully and saved on json
# How to Run
``bash
python -m pip install requests beautifulsoup4
python book_scraper.py
``
