# Mentee Project

## Overview

Mentee Project is a Python application developed to demonstrate programming concepts and practical software development skills.

## Features

* Performs the application's core functionality.
* Uses Python for implementation.
* Includes a structured and maintainable codebase.

## Technologies Used

* Python 3.12
* Git
* GitHub

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Sayomiii/mentee-project.git
```

### 2. Navigate to the project directory

```bash
cd mentee-project
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 4. Install dependencies

If a `requirements.txt` file exists, run:

```bash
pip install -r requirements.txt
```

## Usage

Run the main Python file:

```bash
streamlit run scrim.py
```
